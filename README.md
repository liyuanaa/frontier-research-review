# Frontier Research Review · 经管前沿文献库

每日追踪 FT50 / UTD24 顶刊论文的个人文献库：全部收录、按相关性与重要性综合评分排序，
可检索、按两级主题筛选、可展开阅读卡（英文原摘要 + 中文深度解读：摘要/方法/数据/结论/启发）。

> 纯静态单页应用，数据内嵌于 index.html，每天 8:30 由本地流水线自动重建并推送。

## 使用
- 打开 GitHub Pages 链接即可（或下载 index.html 双击离线使用）。
- 顶部右侧图标直达 GitHub / 谷歌学术 / Sci-Hub / ScienceDirect / Elsevier / Web of Science。
- 支持深色模式（右上角切换）、排序（综合分/重要性/相关性/日期）、每页 50 条分页。
